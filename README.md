# Fluxy

## Sobre o Projeto

O **Fluxy** é um sistema de gestão financeira desenvolvido para auxiliar no controle e organização das finanças pessoais e empresariais.

A aplicação permite o gerenciamento de receitas, despesas, fornecedores, estoque, clientes e relatórios financeiros, oferecendo uma visão completa da saúde financeira do negócio por meio de uma interface web intuitiva e de fácil utilização.

O projeto foi criado com o objetivo de centralizar informações financeiras em um único ambiente, facilitando a tomada de decisões e o acompanhamento do fluxo de caixa.

---

## Funcionalidades

- Cadastro e gerenciamento de receitas
- Cadastro e controle de despesas
- Controle de fluxo de caixa
- Dashboard com indicadores financeiros
- Gestão de clientes
- Gestão de fornecedores
- Controle de estoque
- Configurações personalizadas do sistema
- Relatórios financeiros
- Perfil de usuário
- Interface web responsiva
- Persistência de dados através de API local
